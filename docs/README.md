# CareerCarte Docs

## 目的

このディレクトリは、CareerCarte における要件整理、論点管理、設計判断の根拠を蓄積するための場所です。

現時点では、`+Story platform` から抽出した CSV 学習データを活用し、次の 2 つを実現するための議論を進めます。

| テーマ | 狙い |
| --- | --- |
| 強制力の伴う教育の追跡 | 受講率 100% を漏れなく、低負荷で達成できる運用を作る |
| キャリア・スキル支援への活用 | 任意学習や外部講座を、個人と組織の成長に結びつける |

## 議論の進め方

議論は次の順で進めます。

1. 目的と課題を固定する
2. データ区分ごとの制約と閲覧権限を固定する
3. MVP で実現する業務を絞る
4. その後に画面・データモデル・運用設計へ落とす

先に UI や実装方式へ進むと、機密性と業務責任範囲の整理が後戻り要因になります。したがって、このリポジトリでは当面 `要件定義 -> 業務設計 -> 実装設計` の順を維持します。
